# 晴途 Qingtu：界面与品牌改版

## 定位

产品展示名：晴途 Qingtu。标语：“把好心情，安排进旅程。”
晴代表明朗、轻松，途对应地点、路线与日程；避免把“安全”包装成无法保证的旅行承诺。
首页明确展示来源与估算边界，不承诺实时天气、无限免费、全球覆盖或已验证的预约。

这是基于开源项目的二次开发，来源见 [上游说明](UPSTREAM.md)。保留上游来源说明及已有版权/许可证信息；改外观不代表
可以冒称所有代码均为原创。仓库目录、数据库、已有 API 路径和历史技术文档保留兼容。

## 视觉体系

- 彩色雾青底 #D7E7E1，叠加松绿、湖蓝和暖杏静态柔和渐变；浅松绿卡片 #EAF1E5，深青绿主色 #155E53。
- 墨绿正文 #1E3C35，灰绿辅助文字 #465F55，暖杏点缀 #EAB27B。
- 自绘矢量 Logo、路线与山丘插画、城市文字明信片；不使用外部图片或远程字体。
- 大标题与充分留白，圆角卡片，低对比边框；取消原有大面积紫色渐变和持续背景动画。
- 白字/深青绿按钮与正文/暖白背景进行了色值对比度计算；这不等于完整 WCAG 审计。

## 信息架构与行为

1. 首页：明确的开始规划入口、三步使用说明、四城直达、信息来源说明、多城市次级入口。
2. 选城市：默认卡片与中文/英文搜索，国内/国外切换保留，世界地图放入可选折叠面板。
3. 定偏好：日期、包含首尾日的天数、预算、节奏和兴趣优先；住宿路线与 AI 筛选放入高级选项。
4. 看行程：日期导航、地图与时间轴；移动端日期列表横向滚动，主要操作可换行。
5. 登录：无需登录先规划，保存时再登录；Google OAuth 原逻辑保留，没有新增账号体系。
6. 首页城市入口使用 query 参数，城市 ID 仍从后端实时获取，不硬编码数据库 ID。
7. 去掉按定时器伪造的进度百分比，加载中只描述正在处理及预计等待范围。
8. 主要表单增加可访问名称；按钮保留文本，键盘焦点可见，支持减少动画偏好和跳到正文。
9. 错误消息保持可见直到关闭，成功/信息消息自动关闭；避免短暂错误提示来不及阅读。

## 人工查看清单

打开 http://localhost:3000 ，如仍显示旧样式可按 Ctrl+F5。
检查首页“开始规划”和城市卡片能否进入正确城市，试一次中文/英文城市搜索，切换国内/国外。
在偏好页设置日期，确认天数含首尾日；展开“更多安排”检查真实路线与 AI 选项。
生成结果后切换日期，查看地图、来源和费用提示；测试保存/分享时的登录提示。
使用手机窄屏检查导航、卡片、按钮、日期横向列表；按 Tab 检查焦点能否看见。

当前模型与数据服务可用性以后台状态为准；本轮 UI 改版不修复此前的 DeepSeek 401。
