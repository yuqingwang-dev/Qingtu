# 上游来源与 Qingtu 更名兼容说明

Qingtu（晴途）基于 RouteMind 开源项目进行二次开发。产品更名不改变上游代码归属，
也不替代或移除适用的原版权、许可证与署名要求。历史方案中的 TripPilot 是早期工作名。

现行产品/代码/服务名统一为 Qingtu / qingtu；原名称仅在来源、历史记录和迁移兼容信息中保留。

## 现有安装

- 本工作区实际路径仍为 `D:\RouteMind`。不在运行中移动仓库根目录或虚拟环境；新克隆可以放在 Qingtu 目录。
- 当前本地 `.env` 继续指向已有数据库 `routemind`，以保留已有用户和行程。新安装默认数据库为 `qingtu`。
- 当前本地 `.env` 的 POSTGRES_VOLUME_NAME / REDIS_VOLUME_NAME 指向旧数据卷；新安装默认使用 qingtu 前缀。
- 不执行数据库重命名、清空、数据卷删除或正在运行容器迁移。旧 Docker 容器如仍运行，应先正常停止对应旧服务再启动新配置，避免端口冲突；不要使用 down -v。
- 浏览器第一次读取新命名空间时，会把旧 session 和 itinerary storage 的值复制到 Qingtu 命名空间；旧数据保留备份。主动清除会话时会同时清除旧会话键，避免恢复旧会话。
- 历史 DOCX 与设计记录保留原始历史信息，不用二进制替换修改文档；当前品牌说明以 README 与 qingtu_ui.md 为准。

更名没有改变请求路径、端口、OAuth 凭据或接口错误码。
